Enterprise Software System

Two Platforms. Complete Control. Total Visibility.

ArcaKnox Shield and KeyKnox Shield form the intelligent software backbone of Meclix systems — replacing fragmented spreadsheets with centralized database control and compliance logs.

🛡️ ArcaKnox Shield (Smart Locker Software)

Centralized locker management platform used to configure, manage, and monitor locker operations across facilities and locations.

  • Layout Builder: Configure cabinet sections, size groupings, and location maps.
  • User Rules: Allocate lockers automatically based on employee shift schedules.
  • Role-Based Access: Deployment Admin, Facility Manager, and Service Desk roles.
  • Active Audits: Export detailed occupancy and entry files to Excel and PDF.

🔑 KeyKnox Shield (Key Cabinet Software)

Centralized key control platform mapping physical key hook matrices and monitoring connectivity status across sites.

  • Matrix Configurator: Map key tags to specific row/column slots in cabinets.
  • Key Status Dashboard: View "Key In", "Key Out", "Lost", or "Disabled" statuses.
  • Overdue Monitor: Real-time tracker flags keys held past designated return shifts.
  • System Logs: Records user IDs, biometric verification states, and access events.
